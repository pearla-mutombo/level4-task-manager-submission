# Day 3 — Python Task Summary

## What This Script Does

For my Week 1 Day 3 assignment, I created a Python script that counts completed and incomplete tasks.

The script uses a list of dictionaries to store four sample tasks. Each task has an ID, a title, and a completion status.

I created three functions:

- `count_completed_tasks()` counts tasks that are completed.
- `count_incomplete_tasks()` counts tasks that are not completed.
- `print_task_summary()` displays the total number of tasks and their completion status.

The script uses `for` loops and `if` statements to check each task.

## How to Run the Script

Open Terminal and navigate to the `level4-task-manager` project folder.

Run:

```bash
backend/.venv/bin/python exercises/day-03/task_summary.py
```

## Expected Output

```text
===== DAY 3 TASK SUMMARY =====
Total tasks: 4
Completed tasks: 2
Incomplete tasks: 2
==============================
```

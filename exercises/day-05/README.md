# Friday Practice — Verify and Hand Off

**180 minutes.** Complete required checkpoint corrections before optional enhancements.

## 0–60 minutes: corrections

Use your instructor's checkpoint notes. For each gap, write the observed problem, correction, and evidence from repeating the original action. A working demonstration, explanation, and small modification are all required.

## 60–105 minutes: verification matrix

Record pass/fail evidence for:

- Health JSON displayed in React.
- Create, list, detail, edit, completion, and delete through the frontend.
- Valid and invalid Postman requests, including wrong completion type.
- A mixed-field rejected update leaving the record unchanged.
- No tasks and no matches for a selected filter.
- Loading under browser network throttling.
- Backend stopped → readable error → restored server → successful retry.
- Browser refresh preserving server memory.
- Server restart restoring seed data.
- Direct refresh of a valid task-detail URL.
- Automated backend and prepared frontend checks.

Do not claim browser-refresh persistence after a server restart; those are different operations.

## 105–150 minutes: application README

Write a reproducible setup guide for a reader with Python 3.13 and Node 24. Include installation/activation commands, two-terminal startup, addresses, configuration examples, tests, supported endpoints, and the in-memory limitation. Explain which frontend code was provided and which backend code you implemented.

## 150–180 minutes: final daily PR

Submit your corrections, README, verification evidence, and any remaining blockers. Include repository/PR links, test output, and a short demonstration recording or annotated screenshots if requested by your instructor.

End with three sentences explaining what PostgreSQL should improve next week. Keep all working application code for Week 2.

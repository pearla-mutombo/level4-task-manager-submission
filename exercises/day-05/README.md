# Day 5: Reading List Report

## Project Description

For my Day 5 Python assignment, I created a Reading List Report program that reads information from a JSON file, counts the books, and creates a text report showing the book titles.

This exercise helped me practice working with Python functions, importing functions from another Python file, reading and writing files, and handling errors.

## Files Used

- `reading_report.py` — The main Python program that reads the JSON file and creates the report.
- `report_utils.py` — A separate Python module containing the `count_books()` and `get_book_titles()` functions.
- `../../sample-data/reading-list.json` — The original JSON file containing the book information.
- `reading-report.txt` — The output file generated by the program.

## How to Run the Program

1. Open Terminal.
2. Navigate to the main `level4-task-manager` project folder.
3. Run the following command:

   `python exercises/day-05/reading_report.py`

The program displays the report in Terminal and saves a copy to `exercises/day-05/reading-report.txt`.

## Example Output

```text
MY READING LIST REPORT
======================
Total books: 2

Book titles:
1. Flask quickstart
2. Python virtual environments
```

## Python Concepts Practiced

- **Functions:** I used separate functions to load books, create the report, and save the results.
- **Imports:** I imported two helper functions from `report_utils.py`.
- **JSON:** I used Python's `json` module to read book information.
- **File handling:** I practiced reading a JSON file and writing a text file.
- **Loops:** I used a loop to number each book title.
- **Error handling:** I handled missing files, invalid JSON, and unexpected data.

## What I Learned

This assignment helped me understand how multiple Python files can work together. Instead of putting all the code into one function, I separated the program into smaller functions with different responsibilities.

I also learned how to read data from one file, process it, and save the results to another file without changing the original data.

## My Day 5 Reflection: Challenges, Solutions, and What I Learned

### Challenges I Experienced

One challenge I experienced was organizing my Python program into separate files and understanding how to import functions from another Python module.

While working on the assignment, I also encountered a problem when I tried to open `report_utils.py` in Visual Studio Code. The Terminal could not open the file because it had not been created yet.

I needed to understand why the command failed and how to correct the problem before continuing.

### How I Resolved These Challenges

I reviewed the file location and realized that `report_utils.py` needed to exist before I could open it.

I used the Terminal command `touch` to create the missing file. After that, I was able to open it in Visual Studio Code and add my helper functions.

I organized the program so that `report_utils.py` contained the functions for counting books and collecting book titles, while `reading_report.py` handled reading the JSON file, creating the report, and saving the output.

I then ran the program from Terminal to verify that everything worked correctly.

The program successfully read the JSON file, counted two books, displayed their titles, and saved the report to `reading-report.txt`.
